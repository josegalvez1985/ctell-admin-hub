# Ctell Admin Hub

Sistema administrativo web y PWA para CTELL: compras, ventas, stock, tesorería
y recursos humanos, con login de usuarios. Construido en React con TanStack
Start y Tailwind, con diseño responsive para escritorio y móvil.

## Development

Necesitas Node.js y npm — [instalar con nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
